# Cactus RAG Preprocessor: Schema Extraction & Implementation Plan

## Overview

This document provides the extracted ObjectBox schema used by `cactus-flutter` for RAG (Retrieval-Augmented Generation) and a complete implementation plan for building a Dart CLI tool that can pre-process documents on a host machine, generating a portable ObjectBox database that can be transferred to mobile devices.

---

## Part 1: Extracted ObjectBox Schema

Based on analysis of the cactus-flutter SDK documentation and API references, here is the complete schema:

### Entity: Document

```dart
import 'package:objectbox/objectbox.dart';

@Entity()
class Document {
  @Id()
  int id = 0;

  /// Name of the document file (e.g., "readme.txt")
  String fileName;

  /// Original file path where the document was loaded from
  String filePath;

  /// Timestamp when document was first stored
  @Property(type: PropertyType.date)
  DateTime? createdAt;

  /// Timestamp when document was last updated
  @Property(type: PropertyType.date)
  DateTime? updatedAt;

  /// Size of the original file in bytes
  int? fileSize;

  /// Hash of the file content for versioning/deduplication
  String? fileHash;

  /// Relation to all chunks belonging to this document
  final chunks = ToMany<DocumentChunk>();

  Document({
    required this.fileName,
    required this.filePath,
    this.createdAt,
    this.updatedAt,
    this.fileSize,
    this.fileHash,
  });

  /// Getter to reconstruct full document content from chunks
  String get content => chunks.map((c) => c.content).join('');
}
```

### Entity: DocumentChunk

```dart
import 'package:objectbox/objectbox.dart';

@Entity()
class DocumentChunk {
  @Id()
  int id = 0;

  /// The text content of this chunk
  String content;

  /// Vector embeddings for semantic search
  /// Uses HNSW index with 1024 dimensions and squared Euclidean distance
  @HnswIndex(
    dimensions: 1024,
    distanceType: VectorDistanceType.euclidean,
  )
  @Property(type: PropertyType.floatVector)
  List<double>? embeddings;

  /// Back-reference to the parent document
  final document = ToOne<Document>();

  DocumentChunk({
    required this.content,
    this.embeddings,
  });
}
```

## Part 2: Chunking Algorithm

The chunking algorithm used by CactusRAG:

```dart
/// Splits content into overlapping chunks
List<String> chunkContent(
  String content, {
  int chunkSize = 512,
  int chunkOverlap = 64,
}) {
  final chunks = <String>[];
  var start = 0;
  
  while (start < content.length) {
    final end = (start + chunkSize).clamp(0, content.length);
    chunks.add(content.substring(start, end));
    
    // Move forward by (chunkSize - overlap) to create overlap
    start += chunkSize - chunkOverlap;
  }
  
  return chunks;
}
```

**Example:**
- Content: 1000 characters
- chunkSize: 512, chunkOverlap: 64
- Chunks: [0-512], [448-960], [896-1000]
- Result: 3 chunks with 64-char overlaps

### Phase 3: Implement Services

#### 3.1 lib/services/chunker.dart

```dart
class Chunker {
  final int chunkSize;
  final int chunkOverlap;

  Chunker({
    this.chunkSize = 512,
    this.chunkOverlap = 64,
  });

  List<String> chunk(String content) {
    if (content.isEmpty) return [];
    
    final chunks = <String>[];
    var start = 0;

    while (start < content.length) {
      final end = (start + chunkSize).clamp(0, content.length);
      chunks.add(content.substring(start, end));
      start += chunkSize - chunkOverlap;
    }

    return chunks;
  }
}
```

#### 3.2 lib/services/embedder.dart

```dart
import 'dart:convert';
import 'dart:io';

/// Abstract interface for embedding generation
abstract class Embedder {
  Future<List<double>> embed(String text);
  Future<void> initialize();
  void dispose();
}

/// Embedder using Cactus CLI (subprocess)
class CactusCliEmbedder implements Embedder {
  final String modelPath;
  final String cactusBinaryPath;
  
  CactusCliEmbedder({
    required this.modelPath,
    this.cactusBinaryPath = 'cactus',
  });

  @override
  Future<void> initialize() async {
    // Verify model exists
    if (!await File(modelPath).exists()) {
      throw Exception('Model not found: $modelPath');
    }
  }

  @override
  Future<List<double>> embed(String text) async {
    // Call cactus CLI for embedding
    // This is a placeholder - actual implementation depends on Cactus CLI interface
    final result = await Process.run(
      cactusBinaryPath,
      ['embed', '--model', modelPath, '--text', text],
    );
    
    if (result.exitCode != 0) {
      throw Exception('Embedding failed: ${result.stderr}');
    }
    
    // Parse JSON output containing embeddings
    final json = jsonDecode(result.stdout as String);
    return (json['embeddings'] as List).cast<double>();
  }

  @override
  void dispose() {}
}

/// Embedder using HTTP API (e.g., Ollama, OpenAI-compatible)
class HttpEmbedder implements Embedder {
  final String apiUrl;
  final String modelName;
  final HttpClient _client = HttpClient();

  HttpEmbedder({
    required this.apiUrl,
    required this.modelName,
  });

  @override
  Future<void> initialize() async {}

  @override
  Future<List<double>> embed(String text) async {
    final request = await _client.postUrl(Uri.parse('$apiUrl/embeddings'));
    request.headers.contentType = ContentType.json;
    request.write(jsonEncode({
      'model': modelName,
      'input': text,
    }));
    
    final response = await request.close();
    final body = await response.transform(utf8.decoder).join();
    final json = jsonDecode(body);
    
    return (json['data'][0]['embedding'] as List).cast<double>();
  }

  @override
  void dispose() {
    _client.close();
  }
}
```

#### 3.3 lib/services/database.dart

```dart
import 'package:objectbox/objectbox.dart';
import '../models/document.dart';
import '../models/document_chunk.dart';
import '../objectbox.g.dart';

class RagDatabase {
  late Store _store;
  late Box<Document> _documentBox;
  late Box<DocumentChunk> _chunkBox;

  Future<void> open(String directory) async {
    _store = await openStore(directory: directory);
    _documentBox = _store.box<Document>();
    _chunkBox = _store.box<DocumentChunk>();
  }

  void close() {
    _store.close();
  }

  Future<Document> storeDocument({
    required String fileName,
    required String filePath,
    required List<String> chunkContents,
    required List<List<double>> embeddings,
    int? fileSize,
    String? fileHash,
  }) async {
    final now = DateTime.now();
    
    final document = Document(
      fileName: fileName,
      filePath: filePath,
      createdAt: now,
      updatedAt: now,
      fileSize: fileSize,
      fileHash: fileHash,
    );

    // Create chunks with embeddings
    for (var i = 0; i < chunkContents.length; i++) {
      final chunk = DocumentChunk(
        content: chunkContents[i],
        embeddings: embeddings[i],
      );
      chunk.document.target = document;
      document.chunks.add(chunk);
    }

    _documentBox.put(document);
    return document;
  }

  List<Document> getAllDocuments() => _documentBox.getAll();

  int get documentCount => _documentBox.count();
  int get chunkCount => _chunkBox.count();
}
```

### Phase 4: CLI Implementation

#### 4.1 bin/preprocess.dart

```dart
import 'dart:io';
import 'package:args/args.dart';
import 'package:crypto/crypto.dart';
import 'package:path/path.dart' as path;

import 'package:cactus_rag_preprocessor/services/database.dart';
import 'package:cactus_rag_preprocessor/services/chunker.dart';
import 'package:cactus_rag_preprocessor/services/embedder.dart';

void main(List<String> arguments) async {
  final parser = ArgParser()
    ..addOption('input', abbr: 'i', help: 'Input directory or file', mandatory: true)
    ..addOption('output', abbr: 'o', help: 'Output ObjectBox directory', mandatory: true)
    ..addOption('model', abbr: 'm', help: 'Path to embedding model')
    ..addOption('api-url', help: 'Embedding API URL (e.g., http://localhost:11434/api)')
    ..addOption('api-model', help: 'Model name for API', defaultsTo: 'nomic-embed-text')
    ..addOption('chunk-size', help: 'Chunk size in characters', defaultsTo: '512')
    ..addOption('chunk-overlap', help: 'Chunk overlap in characters', defaultsTo: '64')
    ..addMultiOption('extensions', abbr: 'e', help: 'File extensions to process', defaultsTo: ['.txt', '.md'])
    ..addFlag('verbose', abbr: 'v', help: 'Verbose output')
    ..addFlag('help', abbr: 'h', help: 'Show help');

  final args = parser.parse(arguments);

  if (args['help'] as bool) {
    print('Cactus RAG Preprocessor\n');
    print('Usage: dart run preprocess.dart [options]\n');
    print(parser.usage);
    exit(0);
  }

  final inputPath = args['input'] as String;
  final outputPath = args['output'] as String;
  final chunkSize = int.parse(args['chunk-size'] as String);
  final chunkOverlap = int.parse(args['chunk-overlap'] as String);
  final extensions = args['extensions'] as List<String>;
  final verbose = args['verbose'] as bool;

  // Initialize embedder
  late Embedder embedder;
  if (args['api-url'] != null) {
    embedder = HttpEmbedder(
      apiUrl: args['api-url'] as String,
      modelName: args['api-model'] as String,
    );
  } else if (args['model'] != null) {
    embedder = CactusCliEmbedder(modelPath: args['model'] as String);
  } else {
    print('Error: Either --model or --api-url must be specified');
    exit(1);
  }

  await embedder.initialize();

  // Initialize components
  final chunker = Chunker(chunkSize: chunkSize, chunkOverlap: chunkOverlap);
  final database = RagDatabase();
  
  await database.open(outputPath);

  // Collect files to process
  final files = <File>[];
  final input = FileSystemEntity.typeSync(inputPath);
  
  if (input == FileSystemEntityType.file) {
    files.add(File(inputPath));
  } else if (input == FileSystemEntityType.directory) {
    await for (final entity in Directory(inputPath).list(recursive: true)) {
      if (entity is File) {
        final ext = path.extension(entity.path).toLowerCase();
        if (extensions.contains(ext)) {
          files.add(entity);
        }
      }
    }
  }

  print('Found ${files.length} files to process');
  
  // Process each file
  var processed = 0;
  for (final file in files) {
    try {
      if (verbose) print('Processing: ${file.path}');
      
      final content = await file.readAsString();
      final chunks = chunker.chunk(content);
      
      if (verbose) print('  → ${chunks.length} chunks');

      // Generate embeddings for each chunk
      final embeddings = <List<double>>[];
      for (var i = 0; i < chunks.length; i++) {
        if (verbose) print('  → Embedding chunk ${i + 1}/${chunks.length}');
        final embedding = await embedder.embed(chunks[i]);
        embeddings.add(embedding);
      }

      // Compute file hash
      final bytes = await file.readAsBytes();
      final hash = md5.convert(bytes).toString();

      // Store in database
      await database.storeDocument(
        fileName: path.basename(file.path),
        filePath: file.path,
        chunkContents: chunks,
        embeddings: embeddings,
        fileSize: bytes.length,
        fileHash: hash,
      );

      processed++;
      print('[$processed/${files.length}] ${path.basename(file.path)} → ${chunks.length} chunks');
      
    } catch (e) {
      print('Error processing ${file.path}: $e');
    }
  }

  print('\n✓ Processing complete!');
  print('  Documents: ${database.documentCount}');
  print('  Chunks: ${database.chunkCount}');
  print('  Output: $outputPath');

  database.close();
  embedder.dispose();
}
```

## Part 4: Critical Compatibility Notes

### Schema Must Match Exactly

The ObjectBox schema in your preprocessor **must match** the cactus-flutter schema exactly:

1. **Entity names**: `Document`, `DocumentChunk`
2. **Property names and types**: Must be identical
3. **HNSW index configuration**: 1024 dimensions, Euclidean distance
4. **Relations**: `ToMany<DocumentChunk>` on Document, `ToOne<Document>` on DocumentChunk

### ObjectBox Version Compatibility

- Use the **same ObjectBox version** as cactus-flutter
- Check cactus-flutter's `pubspec.yaml` for the exact version
- Current cactus uses `objectbox: ^4.0.0`

### Embedding Dimensions

- Cactus models produce **1024-dimensional** embeddings by default
- If using a different embedding model, ensure it produces 1024 dimensions
- Alternatively, you'll need to modify the schema and the mobile app

### Option B: Sentence Transformers (Python)

Create a small HTTP server that wraps sentence-transformers:

```python
# embedding_server.py
from flask import Flask, request, jsonify
from sentence_transformers import SentenceTransformer

app = Flask(__name__)
model = SentenceTransformer('all-MiniLM-L6-v2')  # 384 dims - need to match

@app.route('/embeddings', methods=['POST'])
def embed():
    text = request.json['input']
    embedding = model.encode(text).tolist()
    return jsonify({'data': [{'embedding': embedding}]})

if __name__ == '__main__':
    app.run(port=8080)
```
